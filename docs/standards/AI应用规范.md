## AI 应用规范

### AI-01 有依据回答与可追溯出处

检索仅使用当前有权限、已就绪、未删除的资料；有明确设备时必须限定该设备或明确适用的实验室通用资料。组合关键词与向量检索，输出片段携带 material_id、版本、chunk_id、章节及可用页码或段落定位。

回答中的操作步骤和故障判断须得到当前检索片段支持。资料不足、相互矛盾或无法确定设备型号时，先说明限制并追问，不补造说明或出处。出处由服务端从本轮检索结果构建和校验，不信任模型任意生成的 ID 或 URL。

**检查判据：** 逐项核对固定评测回答中的关键步骤；每个出处属于本轮授权证据，且可打开对应版本原文；无依据样例明确说明不足。

### AI-02 三项产品技能有清晰契约

| 技能     | 适用场景与必要信息              | 执行步骤                      | 输出要求                 |
| ------ | ---------------------- | ------------------------- | -------------------- |
| 设备使用指导 | 查询操作；设备及必要型号明确         | 校验范围 → 检索 → 组织有依据步骤       | 步骤、注意事项、出处或资料不足说明    |
| 故障分步排查 | 描述故障；设备、现象、已做操作        | 补齐信息 → 检索 → 安全筛选 → 逐步追问结果 | 当前可执行的安全步骤、出处、停止排查条件 |
| 报修信息整理 | 无法解决或用户要求报修；设备、故障、排查记录 | 汇总 → 补齐必要字段 → 生成草稿        | 可编辑报修摘要和确认入口，不直接提交   |

每项技能保存名称、版本、必要字段、允许工具、停止条件和输出格式。默认每轮最多执行 8 次工具调用；达到上限时结束本轮并说明进展。技能内容不能覆盖鉴权、确认和高风险操作边界。

**检查判据：** 缺字段时追问；达到上限不循环；技能版本可追溯；无关技能不能调用超出其允许列表的工具。

### AI-03 MCP 工具契约与写操作边界

独立 MCP Server 至少提供以下工具。

| 工具名                       | 主要参数                      | 约束                  |
| ------------------------- | ------------------------- | ------------------- |
| `query_devices`           | 名称、状态等筛选条件                | 实验室身份来自受信任上下文       |
| `query_availability`      | device_id、start_at、end_at | 结果表示查询时可用，不保证后续提交成功 |
| `create_reservation`      | draft_id、确认凭证、幂等键         | 只消费已由用户确认的预约草稿      |
| `cancel_reservation`      | draft_id、确认凭证、幂等键         | 重新检查所有者、时间与当前状态     |
| `create_work_order`       | draft_id、确认凭证、幂等键         | 只消费已确认报修草稿          |
| `query_work_order_status` | work_order_id             | 按用户范围返回状态和可见处理记录    |

启动时验证工具发现结果与所需 schema 一致。参数须在 MCP 入口和业务入口校验，拒绝未声明字段；工具输出使用明确的成功、业务拒绝、依赖失败状态。确认凭证由可信应用层在用户点击确认后注入，不经过模型生成或从模型文本提取。

**检查判据：** 未确认时模型即使请求写工具也无法写入；伪造参数、工具返回的恶意指令和错误状态不被解释为授权；发现缺少工具时报告能力不可用。

### AI-04 提示词与模型变更评测

提示词、模型标识、生成参数、技能、检索参数和工具 schema 均纳入版本管理。固定评测集不少于 30 条，覆盖有依据问答、无依据、型号不明、危险操作、提示注入、预约冲突、写操作确认和工具失败，每类至少 3 条；样例可具有多个标签。

评测至少记录：关键事实是否正确、出处是否有效、是否应拒答、工具及参数是否正确、是否出现未确认写入。真实模型评测完整重复 2 次，分别报告结果，不只取较好一次。两次均须满足权限泄露、未确认写入、高风险步骤输出为 0；有依据样例回答合格率不低于 90%，无依据样例正确说明不足率不低于 90%，所有已输出出处的有效率为 100%。这些为初稿门槛，调整须评审并保留旧结果。

**检查判据：** 报告保留数据集版本、分母、逐例结论、模型和配置；人工复核所有失败样例及至少 5 条通过样例，不以另一个模型单独打分代替核查。
