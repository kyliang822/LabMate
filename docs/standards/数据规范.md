## 数据规范

### DATA-01 核心实体及约束

| 实体         | 必要字段或关系                                                  | 关键约束             |
| ---------- | -------------------------------------------------------- | ---------------- |
| 用户与实验室成员关系 | user_id、lab_id、role                                      | 角色与归属由服务端维护      |
| 设备         | device_id、lab_id、名称、型号、位置、状态                             | 状态为可用、停用、维修中     |
| 资料及版本      | material_id、lab_id、device_id（可空）、version、文件摘要、存储键        | 通用资料设备可空；实验室必填   |
| 切片         | chunk_id、material_id、version、chunk_index、原文、定位、embedding | 归属与资料一致，版本内序号唯一  |
| 预约         | reservation_id、lab_id、device_id、user_id、起止时间、状态          | 有效预约区间不得重叠       |
| 工单及处理记录    | work_order_id、lab_id、device_id、提交人、状态、处理人、version        | 状态变更有操作者、时间及说明   |
| 会话与消息      | conversation_id、user_id、lab_id、内容、出处快照                   | 仅授权用户可见          |
| 操作草稿与幂等记录  | draft_id、用户、操作类型、参数摘要、有效期、结果 ID                          | 不可由模型自行设置确认状态    |
| 异步任务       | task_id、资料版本、阶段、状态、错误、重试次数                               | 状态与任务结果可核对       |
| 审计记录       | actor_id、action、target_id、结果、时间、关联 ID                    | 追加写入，普通业务界面不允许修改 |

业务时间以带时区的时间保存，数据库统一 UTC，界面按 Asia/Shanghai 展示并标明时区；无时区的自然语言时间须按界面时区解析并在确认摘要展示。数据库使用外键、唯一约束及必要索引，不仅依赖应用层检查。

**检查判据：** 非法外键、重复切片、重叠有效预约不能入库；前端、后端与数据库对同一预约时间解释一致。

### DATA-02 资料生命周期与异步一致性

资料任务状态统一为“排队中、处理中、已就绪、失败”，失败记录解析、切分、向量化或入库阶段。仅已就绪版本参与检索。处理中的切片先保存在不可见版本，成功后原子切换可检索版本；失败不能暴露半成品。

Celery 任务按至少一次投递设计，使用资料版本及任务阶段实现幂等。重复执行不生成重复切片；瞬时故障自动重试最多 2 次，格式错误不自动重试；管理员可在修正原因后手动重试，记录新尝试。

**检查判据：** 同一任务重复投递后结果数量及内容一致；处理中杀死 worker，恢复后状态可追踪；失败资料不出现在搜索结果中。

### DATA-03 更新、删除与出处保真

更新资料生成新版本，不原地覆盖旧切片；删除采用逻辑删除并立即退出检索，旧版留存用于审计和历史出处核对。打开历史出处仍需校验当前权限，并显示“历史版本”或“资料已停用”；权限被撤销后不得因历史消息而继续访问原文。

业务记录和审计在演示期间默认不提供物理删除。若需清理资料文件或历史记录，须先约定保留期、备份及出处降级策略，执行前核对引用关系。

**检查判据：** 新问答只引用当前有效版本；历史回答不被错误定位到新版本；删除后无法从新检索命中，撤权后不能下载旧文件。

### DATA-04 迁移与演示数据

表结构及向量维度变更必须提供版本化迁移，禁止启动时悄悄改表。更换嵌入模型时保留模型标识、维度、切分策略版本，重新构建独立索引后切换，不混用不同空间的向量。

演示数据只使用虚构用户、预约、故障记录和允许使用的整理资料，注明来源与设备适用范围；演示样例不得冒充设备厂商正式操作规程。

**检查判据：** 空库和上一版本数据库均能按文档迁移；嵌入模型变化后检索无维度错误；演示数据不含真实个人信息或密钥。
