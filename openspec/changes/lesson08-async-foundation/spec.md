# 场景与验收

- F01（T01）：无/失效令牌上传 → 401；无资料、任务、outbox、文件副作用。
- F02（T02）：普通成员上传 → 403；管理员传其他实验室设备与不存在设备 → 相同 404。
- F03（T04）：合法管理员上传 → 202，仅 task_id/status；同键同内容复用任务；同键异内容 409。任务/资料/outbox/审计必须同事务产生。
- F04（T10）：Redis 停止提交 → 202 且 outbox 未发送；恢复 publisher 后可投递。API 代码 MUST 无模型/解析调用；处理结果 MUST 不出现在提交响应。
- F05（SEC-04）：超限、伪后缀、非 UTF-8 拒绝；恶意文件名不能越路径写入；数据库失败不留下新文件。
- F06（DATA-04）：空 PostgreSQL 连续迁移两次成功；同用户同键第二任务插入被唯一约束拒绝。

整课三判据（队友接续，尚未验收）：
1. 前置：消费者可工作且有可测处理耗时；操作：20 次不同键提交，记录 curl time_total，排序取第 19 个；结果：P95 显著小于处理耗时，慢处理不延长请求。
2. 前置：完整 worker；操作：停止 worker、提交、查询 queued，恢复 worker；结果：同 task_id 自动达到 ready，无需重提。
3. 前置：完整幂等消费者；操作：同键重复提交，并在确认前终止 worker 触发重投；结果：只有一份有效切片，attempts 增加，结果摘要不变。
