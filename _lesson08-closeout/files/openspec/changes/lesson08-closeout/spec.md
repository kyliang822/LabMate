# 第八课六项最小闭环

范围：本次补可运行登录、授权关键词检索、真实设备资料检索技能、管理员配置入口、结构化技能审计、Windows统一扫描。原有安全红项不修复，SEC-08不执行，不代签真人评审。

- POST /api/v1/auth/login：安全哈希密码，启用用户验证，短期签名Bearer，数据库摘要与过期/用户状态核对；旧CLI令牌兼容。失败统一401，数据库分钟桶限制请求频率，密码不进日志。
- GET /api/v1/search：关键词匹配，在SQL召回前限定lab、设备/通用资料、当前ready且未删除版本；不得由请求传入user_id/lab_id。返回定位。此为可用的最小关键词检索，不声称完成混合向量RAG。
- GET/PUT /api/v1/ai-config：控制实际检索技能的名称、展示前缀、结果数量；仅本实验室管理员可写，普通使用者403；负载严格校验，版本冲突409，幂等键相同同负载复用原结果；配置变更与审计同事务。配置不改变身份、实验室或工具权限。
- POST /api/v1/skills/material-guide：真正调用受保护检索与配置，输出授权资料片段及出处，无LLM调用；明确它是设备资料查询子技能，不冒充完整故障排查/生成问答。日志实际保存actor_id/lab_id/skill_id/version/config_version/status/duration_ms/usage/request_id；usage标注LLM未调用、0tokens及召回数。
- GET /api/v1/skill-runs/{id}：仅本人且本实验室可读。失败路径也记录，不保存问题原文、片段内容、密码和Token。
- 保留旧迁移，只新增0004。身份初始化仅作用于固定虚构测试用户，密码写0600私密文件，不进报告。更改密码撤销原令牌。
- 一条python命令同时扫描秘密及Python/npm依赖，支持Windows UTF-8及npm.cmd；失败/红项非零退出，原始证据保留。
- 自动验收SEC-02/03/07及登录，动态使用虚构资料，明确记录缺失先决条件；后端真实库测试不能以mock代替。真人另行独立执行同一命令至少两项，署名及意见由人填写。
